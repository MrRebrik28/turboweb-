Режим редактирования прямо в карточках

Включает кнопки правки цены, описания и переключения наличия цветов прямо на карточках витрины (каталог и карточка товара) без входа в админку. Для входа с любого устройства используйте ссылку с ?admin=1 или кнопку «Администрирование» в подвале сайта.

Прямая публикация на сайт (GitHub API)

Поскольку сайт работает на GitHub Pages, локальные правки видны только в этом браузере. Укажите Personal Access Token (права Contents: Read and write), чтобы публиковать обновлённый products.json для всех покупателей в 1 клик.

Экспорт и Импорт каталога

Скачайте актуальный products.json для ручной загрузки на хостинг или выгрузите прайс-лист в CSV (корректно открывается в Excel с русским текстом и цветами).

Массовая переоценка и сброс

Измените цены на весь каталог на заданный процент или сбросьте локальные изменения к исходному файлу products.json с сервера.
