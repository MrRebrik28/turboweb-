# 🚴 TIMETRY BIKES RUSSIA — Чистый светлый интернет-магазин

> **Формат:** Чистый интернет-магазин (Light E-Commerce).  
> **Концепция:** Только суть — крупный оригинальный логотип по центру, контакты, быстрый поиск, фасетные фильтры и прямой доступ к каталогу из 213 моделей.

---

## 💎 Что изменилось в обновленной версии:

1. **Светлый современный дизайн:**
   * Белоснежные и светло-серые карточки товаров (`#ffffff` / `#f8fafc`).
   * Четкая типографика, контрастные цены и спортивные акценты.
2. **Оригинальный 3D-логотип по центру:**
   * Крупный фирменный объемный логотип `TIMETRY` с текстурой карбона по центру шапки (как на оригинале).
3. **Прямой переход к товарам:**
   * Убраны все лишние промо-блоки, квизы и длинные тексты.
   * Покупатель сразу попадает в структурированный каталог с табами категорий и фильтрами.
4. **Умный фасетный фильтр:**
   * Колеса: 29" (найнеры), 27.5", 700C (гравий), 26", 24".
   * Рост: 150–165 см (S), 165–178 см (M), 175–188 см (L), 185+ см (XL).
   * Рама: Алюминий 6061, Карбон, Cr-Mo сталь.
   * Тормоза: Дисковая гидравлика / механика.
   * Живой поиск по моделям (TT428, TT801, Shimano, Cues).
5. **E-Commerce функции:**
   * Покупка в 1 клик, модальное окно быстрого просмотра с галереей фото, корзина с подсчетом суммы и сохранением в браузере.
   * Юридически чистый подвал с реквизитами ИП Ефимов Д.М. (ИНН 420533538981) по 152-ФЗ.

---

## 🚀 Как открыть и протестировать

- **Напрямую в браузере:** двойной клик по файлу `timetry/index.html` (встроен автономный каталог).
- **С полным каталогом (213 моделей):**
  ```bash
  python -m http.server 3000 --directory timetry
  ```
  и перейти по адресу `http://localhost:3000`.
