# 🚀 Настройка микро-шлюза на Yandex Cloud Functions (152-ФЗ + Telegram)

Этот микро-шлюз принимает заявки с лендинга **LocalWeb**, первично логирует их в российском дата-центре Яндекса (выполняя требования ч. 5 ст. 18 закона 152-ФЗ о локализации баз данных) и мгновенно пересылает структурированное уведомление вам в Telegram.

Тариф Yandex Cloud: **Free Tier (до 1 000 000 вызовов в месяц бесплатно)**.

---

## Шаг 1. Получить токен Telegram-бота и ваш Chat ID (2 минуты)

1. Откройте в Telegram официального бота [@BotFather](https://t.me/BotFather).
2. Отправьте команду `/newbot`, придумайте имя (например, `LocalWeb Leads`) и username (например, `localweb_leads_bot`).
3. Скопируйте полученный **токен бота** (вида `7123456789:AAFn8...`).
4. Нажмите кнопку **Start / Запустить** в вашем созданном боте (чтобы он мог писать вам сообщения).
5. Чтобы узнать ваш **Chat ID**, напишите боту [@userinfobot](https://t.me/userinfobot) — он пришлет ваш цифровой ID (например, `123456789`).

---

## Шаг 2. Создать функцию в Yandex Cloud (2 минуты)

1. Перейдите в [Консоль Яндекс Облака](https://console.yandex.cloud/).
2. В левом меню выберите **Cloud Functions** (или перейдите по прямой ссылке [functions](https://console.yandex.cloud/folders)).
3. Нажмите кнопку **«Создать функцию»**:
   * **Название:** `localweb-gateway`
   * Нажмите **«Создать»**.
4. В открывшемся редакторе функции:
   * **Среда выполнения:** выберите `Python 3.11` (или `Python 3.12`).
   * **Точка входа:** укажите `yandex_function.handler` (или `index.handler`, если файл называется `index.py`).
   * Вставьте код из файла `backend/yandex_function.py`.
5. Прокрутите страницу ниже до блока **«Переменные окружения»** и добавьте две переменные:
   * `TELEGRAM_BOT_TOKEN` = ваш токен от BotFather (например, `7123456789:AAFn8...`)
   * `TELEGRAM_CHAT_ID` = ваш цифровой ID (например, `123456789`)
6. Нажмите синюю кнопку **«Сохранить изменения»**.

---

## Шаг 3. Сделать функцию публичной и скопировать ссылку (30 секунд)

1. Нажмите на переключатель **«Публичная функция»** (Public function), чтобы сайт мог отправлять в неё запросы.
2. Скопируйте полученную ссылку на функцию. Она выглядит так:  
   `https://functions.yandexcloud.net/d4e1234567abcdefghij`

---

## Шаг 4. Вставить ссылку в проект

Откройте файл `app.js` и вставьте вашу ссылку в строку 147:
```javascript
window.LEAD_ENDPOINT = 'https://functions.yandexcloud.net/d4e1234567abcdefghij';
```
Или в `index.html` перед подключением `app.js`:
```html
<script>
  window.LEAD_ENDPOINT = 'https://functions.yandexcloud.net/d4e1234567abcdefghij';
</script>
```

Готово! После этого любая заявка с сайта будет моментально прилетать в ваш Telegram и параллельно фиксироваться в российском дата-центре Яндекса.
