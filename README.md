# 🚀 LocalWeb — Автономный агент автопостинга и брендинга ВКонтакте

Интеллектуальный агент для полной автоматизации присутствия студии **LocalWeb** во ВКонтакте:
1. **Генерирует брендовую графику** в строгом соответствии с корпоративным стилем презентации LocalWeb (аватар 800x800, баннер-обложку паблика 1920x768 и 14 карточек постов 1080x1080).
2. **Создает официальный паблик (сообщество)** в ВК, заполняет продающее описание, статус, сайт (`local-web.ru`), контакты и юридические реквизиты.
3. **Устанавливает аватарку и обложку** сообщества.
4. **Заполняет отложку на 14 дней в личном профиле** (по 1 посту в день в 11:00 MSK с прикреплением инфографики).
5. **Заполняет отложку (или предложку) на 14 дней в сообществе** теми же материалами от имени группы.

## 🎨 Дизайн и корпоративный стиль LocalWeb

Все материалы агента разработаны на базе фирменной презентации студии:
- **Цветовая палитра**:
  - Основной синий: `#2563EB` (кнопки, акценты, иконка кода `</>`)
  - Изумрудный/мятный зеленый: `#10B981` / `#059669` (маркеры доверия, бейджи «0 ₽ предоплата», «24ч MVP»)
  - Темный slate: `#0F172A` (заголовки, текст максимальной четкости)
  - Светлый фон: `#F8FAFC` с микросеткой `radial-gradient` и карточками с рамкой `#E2E8F0`
- **Шрифты**: Inter / Segoe UI, жирные заголовки, аккуратные теги-плашки (pills).
- **Ключевые офферы**:
  - Сайт за 24 часа. Сначала рабочий черновик на смартфоне, оплата — потом.
  - 0 ₽ предоплата на старте.
  - 7 500 ₽ финал под ключ.
  - Хостинг 0 ₽ навсегда (чистый HTML5, Tailwind, Vanilla JS на Edge CDN).
  - Скорость загрузки 0.8 сек (98/100 в Google PageSpeed).
  - Домен .RU в собственности клиента (ИП, ООО, физлицо).
  - 100% соблюдение 152-ФЗ РФ и сервер в Москве.
  - Трехуровневая лидогенерация (Telegram-бот 0.5с + Google Таблица + Email).

## 🔑 Шаг 1. Получение токена ВКонтакте

Для создания паблика, загрузки обложек и планирования отложенных постов на стене требуется **User Access Token** с правами:
`wall,groups,photos,offline`.

### Вариант 1 (Быстрый через создание своего Standalone-приложения):
1. Откройте [VK Developers: Мои приложения](https://vk.com/apps?act=manage) и нажмите **«Создать»**.
2. Выберите тип: **«Standalone-приложение»**, укажите любое имя (например, `LocalWeb AutoPost`).
3. В настройках приложения скопируйте **ID приложения** (App ID / Client ID).
4. Перейдите по ссылке в браузере (заменив `YOUR_APP_ID` на ваш ID):
   ```text
   https://oauth.vk.com/authorize?client_id=YOUR_APP_ID&display=page&redirect_uri=https://oauth.vk.com/blank.html&scope=wall,groups,photos,offline&response_type=token&v=5.199
   ```
5. Нажмите **«Разрешить»**.
6. В адресной строке откроется страница `oauth.vk.com/blank.html#access_token=vk1.a.XXXXX...&expires_in=0&user_id=YYYYY`.
7. Скопируйте значение параметра `access_token` — это и есть ваш рабочий токен.

### Вариант 2 (Через файл конфигурации `.env`):
Создайте файл `.env` в корне проекта (скопировав из `.env.example`):
```bash
copy .env.example .env
```
И укажите в нем токен:
```ini
VK_USER_TOKEN=vk1.a.ваш_токен_здесь
```

## 🚀 Шаг 2. Запуск агента

### 1. Проверка расписания и ассетов без публикации (Dry-Run):
```bash
python run_agent.py --dry-run
```
Покажет статус всех 16 графических файлов, дату и время каждого из 14 постов, а также проверит авторизацию в VK.

### 2. Только генерация графики (если нужно обновить картинки):
```bash
python run_agent.py --generate-assets
```
Сгенерирует аватарку, обложку и 14 карточек в папку `vk_agent/assets/`.

### 3. Полный боевой запуск:
```bash
python run_agent.py
```
Или с передачей токена напрямую:
```bash
python run_agent.py --token "vk1.a.ВАШ_ТОКЕН"
```
Что сделает агент:
- Проверит авторизацию вашего профиля.
- Создаст официальный паблик «LocalWeb | Сайты для бизнеса за 24ч без предоплаты».
- Заполнит описание, ссылку на `https://local-web.ru`, контакты разработчика и бота.
- Загрузит обложку (баннер 1920x768) и аватарку (800x800).
- Запланирует 14 постов в **отложку личного профиля** (по 1 посту каждый день в 11:00).
- Запланирует те же 14 постов в **отложку сообщества** от имени паблика.

## ⚙️ Дополнительные опции запуска

| Флаг | Описание |
| :--- | :--- |
| `--dry-run` | Тестовый прогон: проверка токена, дат и ассетов без публикаций |
| `--profile-only` | Опубликовать 14 постов **только в профиль** (не трогая паблик) |
| `--group-only` | Оформить и опубликовать 14 постов **только в паблик** |
| `--group-id 12345` | Использовать существующий паблик вместо создания нового |
| `--as-suggested` | В паблике отправить посты в **предложку** (от пользователя) вместо отложки админа |
| `--start-date 2026-11-01` | Начать отложку с конкретной даты (по умолчанию: завтра) |

## 📅 Контент-план на 14 дней

1. **День 1: Аналитика бизнеса** — Почему одной группы в соцсетях сегодня уже мало (риски блокировок vs личный сайт).
2. **День 2: Тест-драйв 24ч** — Сайт за 24 часа: сначала рабочий черновик, оплата — потом (0 ₽ предоплаты).
3. **День 3: Честное сравнение** — LocalWeb против конструкторов (Tilda) и веб-студий (сравнение цен, хостинга, сроков).
4. **День 4: Технологии** — Скорость загрузки 0.8 сек (Google PageSpeed 98/100) — почему 3 секунды ожидания убивают заявки.
5. **День 5: 152-ФЗ РФ** — 100% защита от штрафов Роскомнадзора до 6 млн ₽ (сервер в Москве, чекбоксы, чеки ФНС).
6. **День 6: Лидогенерация** — Куда приходят заявки: мгновенный Telegram-бот за 0.5с + Google Sheets + резерв почты.
7. **День 7: Собственность** — Домен .RU: почему нельзя оформлять на вебмастера и как мы регистрируем на реквизиты клиента.
8. **День 8: Тариф «Всё включено»** — 8 пунктов за 7 500 ₽ под ключ без мелких шрифтов и скрытых доплат.
9. **День 9: Кейс автосервиса** — Как сайт с ценами и записью окупается за первые 3 дня работы.
10. **День 10: Honeypot-ловушка** — Защита от спам-ботов без раздражающей капчи со светофорами.
11. **День 11: Белая бухгалтерия** — Официальная работа по 422-ФЗ: фискальный чек с QR-кодом для ИП и ООО.
12. **День 12: Сервис** — 30 дней бесплатной гарантии и правок по одному сообщению в Telegram.
13. **День 13: Чек-лист 2026** — 5 признаков сайта, который действительно приносит клиентов в 2026 году.
14. **День 14: Призыв к действию** — Экспресс-бриф за 10 минут: как получить черновик сайта уже завтра.
