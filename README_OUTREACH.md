# 🚀 2-Шаговый агент безопасного аутрича ВКонтакте («Касание без продажи»)

Интеллектуальный агент для масштабируемого поиска клиентов через ВКонтакте по **двухшаговой стратегии («Касание без продажи»)**. 

Позволяет **безопасно отправлять до 35–40 сообщений в день** вместо стандартного лимита в 15 сообщений за счет нейтрализации антиспам-фильтров ВК.

---

## 💡 Принцип работы 2-шаговой стратегии

Антиспам-фильтры ВК мгновенно вычисляют однотипные коммерческие «простыни» со словами *«сайт», «разработка», «лендинг», «7500 руб»* и любые внешние ссылки в первом холодном сообщении. 

Чтобы пробить фильтр, не попасть в спам-лист и получить отклик реального владельца, коммуникация разделена на 2 шага:

```
+----------------------------------------------------------------------------------+
| ШАГ 1: Пинг под видом клиента («Касание без продажи»)                            |
| Короткий естественный вопрос без ссылок и рекламы:                               |
| «Здравствуйте! Подскажите, у вас есть отдельный сайт с актуальным прайсом        |
|  или смотреть все в товарах группы?»                                             |
+----------------------------------------+-----------------------------------------+
                                         |
                                         v
+----------------------------------------------------------------------------------+
| ОЖИДАНИЕ И ФИКСАЦИЯ ОТВЕТА (Listening)                                           |
| Администратор паблика отвечает: «Здравствуйте, сайта нет, все цены здесь».       |
| 👉 ДИАЛОГ СТАНОВИТСЯ ОФИЦИАЛЬНО ВЗАИМНЫМ ДЛЯ АЛГОРИТМОВ ВК                      |
+----------------------------------------+-----------------------------------------+
                                         |
                                         v
+----------------------------------------------------------------------------------+
| ШАГ 2: Продающий оффер во взаимный диалог                                        |
| Спам-фильтр ВК нейтрализован (диалог уже начат собеседником).                    |
| Отправляется готовое предложение: тест-драйв за 24 часа без предоплаты (0 руб), |
| фиксированная цена 7 500 руб, бесплатный пожизненный хостинг и local-web.ru.     |
+----------------------------------------------------------------------------------+
```

---

## 🛡️ Почему теперь можно отправлять 35–40 сообщений в день?

1. **Нет стоп-слов и ссылок в Шаге 1**: 
   - В первом сообщении нет слова *«разработка»*, нет цены *«7 500 ₽»*, нет названия студии *«LocalWeb»* и нет внешних URL.
   - Для нейросетей ВК это рядовой вопрос обычного пользователя, поэтому суточные пороги доверия аккаунта в 2–3 раза выше.
2. **Аномально высокая конверсия в ответ (Reply Rate 40–70%)**:
   - Администраторам коммерческих сообществ платят за ответы клиентам. Они не могут проигнорировать вопрос *«Где посмотреть ваш прайс?»*.
3. **Взаимный статус диалога (Mutual Dialogue)**:
   - Как только сообщество присылает хотя бы один ответ, ВК фиксирует двустороннюю беседу. Во взаимных беседах исходящие ответы уже не классифицируются как холодный спам.

## ⚡ Инструкция по запуску и командам

### 1. Просмотр воронки и статистики
Показывает количество отправленных пингов, процент ответов (CR %), ожидающие офферы и последние ответы администраторов:
```bash
python run_outreach.py --stats
```

### 2. Безопасный предпросмотр (Dry-Run)
*Ищет целевые группы в указанных городах и выводит примеры сгенерированных вопросов Шага 1 без реальной отправки:*
```bash
python run_outreach.py --dry-run --limit 5
```
С указанием конкретных ниш и городов:
```bash
python run_outreach.py --dry-run --niche "детейлинг" "автосервис" --city "Кемерово"
```

### 3. Отправка пингов Шага 1 (Live)
*Отправляет до 25 естественных коротких вопросов группам с безопасными паузами (50–90 сек):*
```bash
python run_outreach.py --step1 --live --limit 25
```

### 4. Проверка входящих ответов от сообществ
*Опрашивает диалоги сообществ через VK API, фиксирует ответы и переводит лиды в статус «Готовы к получению оффера»:*
```bash
python run_outreach.py --check-replies
```

### 5. Отправка офферов Шага 2 (тем, кто ответил)
*Отправляет коммерческое предложение во взаимные диалоги ответившим группам:*
```bash
python run_outreach.py --step2 --live
```

### 6. Полный автопилот (Auto Pipeline)
*В один запуск проверяет новые ответы, отправляет офферы Шага 2 ответившим и затем рассылает свежие пинги Шага 1 в рамках суточной квоты:*
```bash
python run_outreach.py --auto --live --limit 25
```

### 7. Тест генерации шаблонов для одной группы
```bash
python run_outreach.py --test-group 242777884
```

## 📁 Структура файлов

- `run_outreach.py` — консольный интерфейс (CLI) для запуска 2-шаговой стратегии, проверки ответов и просмотра воронки.
- `vk_agent/outreach_agent.py` — ядро агента: фильтрация нецелевых групп, отправка пингов, прослушивание входящих ответов, отправка офферов.
- `vk_agent/spintax.py` — Spintax-генератор коротких клиентских вопросов (Шаг 1) и персонализированных офферов (Шаг 2).
- `vk_agent/database.py` — SQLite база данных (`vk_agent/vk_outreach.db`), отслеживающая статусы `ping_sent` -> `replied` -> `pitch_sent`.
- `vk_agent/vk_api.py` — клиент VK API с методами отправки и получения списка бесед (`messages.getConversations`).
