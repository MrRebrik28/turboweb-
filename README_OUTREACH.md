# 🚀 Автономный агент лидогенерации и безопасного аутрича ВКонтакте (LocalWeb)

Интеллектуальный агент для автоматического поиска потенциальных клиентов (B2B / малый бизнес) через ВКонтакте, глубокого анализа их цифрового присутствия, генерации уникальных персонализированных коммерческих предложений без спама и безопасной отправки в сообщения сообществ.

---

## 🛡️ Архитектура безопасности и защита от блокировок (Anti-Ban Guardrails)

Агент разработан в строгом соответствии с антиспам-политикой и техническими ограничениями ВКонтакте:

1. **Суточные квоты (24-часовое окно)**:
   - Максимум **15–20 сообщений в сутки** на аккаунт.
   - База данных SQLite отслеживает точное время каждой отправки в скользящем окне 24 часа. При исчерпании лимита агент мягко останавливает работу до открытия новой квоты.
2. **Человеческие паузы и джиттер**:
   - Между сообщениями выдерживается случайная пауза **75–140 секунд** (с плавающим джиттером).
   - Каждые 3–4 отправленных сообщения агент делает **микро-паузу на 2.5–4 минуты** (эмуляция естественного перерыва человека).
3. **100% Уникальность текста (Spintax Engine)**:
   - ВКонтакте вычисляет хеши спам-текстов. Отправка одинакового шаблона даже в 5 групп приводит к блокировке.
   - В агент встроен многоуровневый Spintax-генератор с 3 семействами продающих шаблонов, динамической очисткой названия («НА БРОНЕ | ПРЕМИУМ ДЕТЕЙЛИНГ | КЕМЕРОВО» -> `«На Броне»`), вариациями приветствий, аргументов и мягких призывов к действию (более 50 000 уникальных комбинаций).
4. **Умная фильтрация целевой аудитории**:
   - `can_message == 1` — только группы с открытыми сообщениями сообщества.
   - `is_closed == 0` и отсутствие метки `deactivated` (заблокированные / удаленные группы отсекаются сразу).
   - **Sweet spot подписчиков**: от **70 до 25 000**. Отсекает заброшенные/мертвые группы (<70) и федеральные корпорации (>25 000), где модераторы жмут «спам».
   - **Черный список стоп-слов**: исключаются паблики объявлений, барахолки, подслушано, новости, городские чаты.
5. **Классификация качества лида (Lead Scoring)**:
   - `Tier 1 (no_site)`: Сайт отсутствует вообще (бизнес сидит только в ВК и теряет Яндекс Поиск/Карты) — **наивысший приоритет**.
   - `Tier 1 (builder_site)`: В контактах ссылка на taplink, vk.link, tilda.ws (визитка/конструктор с низкой скоростью) — высокий приоритет.
   - `Tier 2 (custom_site)`: Есть отдельный домен — предложение аудита скорости загрузки (0.8 сек) или мобильного редизайна.
6. **Пожизненная дедупликация (SQLite)**:
   - Все найденные, отправленные и отклоненные сообщества сохраняются в `vk_agent/vk_outreach.db`. Сообщество никогда не получит предложение повторно.
7. **Emergency Circuit Breaker (Аварийный останов)**:
   - При получении `error_code: 14` (капча) или `error_code: 9` (flood control) агент **немедленно прекращает цикл**, защищая аккаунт от заморозки.

## ⚡ Быстрый старт

### 1. Просмотр статистики базы и текущей суточной квоты
```bash
python run_outreach.py --stats
```

### 2. Безопасный запуск без отправки (Dry-Run)
*Ищет реальные группы, фильтрует нецелевые, оценивает сайты и выводит готовые уникальные офферы в консоль (ни одного запроса на отправку не совершается):*
```bash
python run_outreach.py --dry-run
```

Поиск по конкретным нишам и городам:
```bash
python run_outreach.py --niche "детейлинг" "автосервис" --city "Кемерово" --limit 5 --dry-run
```

```bash
python run_outreach.py --niche "кухни на заказ" "ремонт квартир" --city "Новосибирск" --limit 5 --dry-run
```

### 3. Тест на конкретном сообществе (по ID группы)
*Позволяет проверить генерацию персонализированного оффера для любой группы:*
```bash
python run_outreach.py --test-group 242777884
```

*Отправить реальное тестовое сообщение в группу (например, в вашу официальную группу LocalWeb):*
```bash
python run_outreach.py --test-group 242777884 --live --yes
```

### 4. Реальная безопасная отправка (Live Mode)
*Отправляет до 5 сообщений с соблюдением безопасных интервалов и подтверждением пользователя:*
```bash
python run_outreach.py --live --limit 5
```

С указанием приоритетных ниш:
```bash
python run_outreach.py --live --limit 5 --niche "детейлинг" "кузовной ремонт" --city "Кемерово"
```

## 📁 Структура модуля аутрича

- `run_outreach.py` — главный консольный интерфейс (CLI) с подробным логированием и защитой.
- `vk_agent/outreach_agent.py` — ядро автономного агента: квалификация групп, скоринг сайтов, координация циклов, соблюдение пауз и аварийные тормоза.
- `vk_agent/spintax.py` — многоуровневый Spintax-генератор, очистка названий брендов от эмодзи и капслока, адаптация под нишу и город.
- `vk_agent/database.py` — база данных SQLite (`vk_agent/vk_outreach.db`), учет лимитов 24ч, статусов сообщений, логов ошибок.
- `vk_agent/vk_api.py` — клиент VK API с поддержкой `groups.search`, `messages.send` в диалоги сообществ (`peer_id = -group_id`), обработки лимитов и токенов.
